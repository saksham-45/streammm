          Configuration

          Adds AAC to the live H.264/HEVC stream (not MJPEG). Pick the default mic, or a loopback device (BlackHole / Loopback) for system audio. Watchers see Unmute — browsers start muted for autoplay. macOS: allow Microphone for Streamaid. Save restarts capture.

          Watchers get a Talk button. Their microphone plays continuously on this Mac's speakers (ffmpeg audiotoolbox / ffplay pipe, afplay fallback). The browser requests echo cancellation. Independent of Capture audio, which is the host mic in the stream.

          Capture audio is on, so Talk is half-duplex: the live stream mutes while you speak, and this Mac's input is ducked so the host mic does not pick up the speakers. Both restore when Talk ends.

          Watchers can join with this password after the 6-digit PIN expires (about 5 minutes). Leave the field blank to keep the current password. Uncheck to disable. Wrong tries are rate-limited like the PIN.

          Prevents idle sleep and display sleep so capture and the publisher stay up (lid close still sleeps). A live remote session always holds this. After wake, capture and the watch link restart immediately. Uncheck to let this Mac sleep when idle.

          This Mac: —

          Sends a magic packet on this LAN (UDP broadcast port 9). Copy this Mac's address and send it from another device on the network after sleep. Firmware Wake-on-LAN must be on; a closed MacBook lid often will not wake.

          Watchers can click (left/right/middle), drag, scroll, type, paste clipboard text or files, and drop files into the host inbox. Incoming files appear on the Desktop and on this Mac's pasteboard as Finder files (Cmd-V). Copy on this Mac (text, PNG, and Finder files) is pushed to the watcher automatically. Uncheck to kill remote input immediately after Save.

          A Send-keys bar appears while remote control is on. Use it for shortcuts the browser would steal (⌘Tab, ⌘W, ⌘Q, Ctrl+Alt+Del, Lock). Same injector the AI uses.

          A session chat panel appears while remote control is on. Host and watchers can message each other without the browser stealing keystrokes into the remote machine.

          While a watcher is driving, this Mac's keyboard and mouse are locked (remote inject still works). Press ⌘⇧Esc to reclaim — the End button will not receive clicks. Requires Accessibility.

          While a watcher is driving, this Mac's displays go black (gamma + brightness) so people nearby cannot see the desktop, including HDR / True Tone panels. The stream still captures the real framebuffer. Press ⌘⇧Esc to unblank and reclaim. Combine with Block local input so the keyboard is locked too.

          When the watcher disconnects or you press End, inject Control+Command+Q (lock screen). Reclaiming with ⌘⇧Esc does not lock.

          Writes the live H.264/HEVC fMP4 to recordings/ (next to config.json) while someone is driving. Reveals the recordings list with Get. MJPEG sessions are not recorded.

          Watchers (and this host page) can submit a task in Have AI use this computer. Cancel AI stops a running loop.

          Restart the service to apply host/port/token changes.
